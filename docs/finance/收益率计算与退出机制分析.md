## 一、背景与问题陈述

在家庭投资基金的日常记账与核算中，普遍采用一个直观的认知模型：
$$\text{收益} = \text{当前资产} + \text{历史累计出金} - \text{历史累计入金}$$

基于此认知，用户提出了关键问题：
1. **现有系统的总收益与总收益率具体是如何实现的？**
2. **如果中途有成员全额退出（清仓赎回），这个逻辑是否会出现漏洞或逻辑崩塌？**

---

## 二、现有系统的计算逻辑

核心计算逻辑位于后端模块：[`lib/calculator.js`](lib/calculator.js)。

### 1. 绝对收益金额 (Profit)
在 `calculateStateFromDb` 函数中：
```javascript
// 基金大盘总收益
const fundProfit = totalNAV.plus(fundExternalWithdraw).minus(fundExternalDeposit);

// 成员个人收益
const profit = currentValue.plus(member.totalWithdraw).minus(member.totalDeposit);
```
- **基金总资产 (Total NAV)**：当前所有在管持仓的总公允市值。
- **外部累计出金 (fundExternalWithdraw)**：自创设以来所有成员流向外部的真实出金额（注：内部成员份额划转 `transfer` 不计入外部出入金，避免干扰基金大盘）。
- **外部累计入金 (fundExternalDeposit)**：自创设以来所有成员从外部投入的真实本金。
- **人民币 (CNH) 口径**：采用同等逻辑，叠加历史出入金汇率与当前即时汇率进行折算。

### 2. 累计总收益率 (Total ROI)
```javascript
// 简单现金流回报率 (Simple Cash ROI)
const fundProfitRate = fundExternalDeposit.isZero() ? ZERO : fundProfit.div(fundExternalDeposit).mul(100);
```
前端首页看板第三张指标卡展示的 **“累计总收益率 (Total ROI)”**，即：
$$\text{累计总收益率} = \frac{\text{当前总资产} + \text{累计出金} - \text{累计入金}}{\text{历史累计总入金}} \times 100\%$$

## 三、成员退出时的逻辑有效性分析

当某个成员决定**全额退出（清仓赎回其全部份额）**时，我们需要将“绝对收益金额”与“收益率百分比”严格区分看待：

### 3.1 绝对收益金额（Profit）：完全准确

对**绝对收益额**而言，现有逻辑在数学与经济学上是**完全成立、客观准确**的。

- **过程拆解**：
  1. 成员退出时，将其名下所有份额按当前单位净值折算为现金，执行出金操作（Withdraw）；
  2. 基金总资产减少了 $\$X$（这部分钱被提取）；
  3. 基金历史累计出金增加了 $\$X$；
  4. 公式中的 $\text{当前资产} + \text{累计出金}$ 总和保持恒定，因此**总收益额不会因为资金离场而发生跳变**。
- **经济学实质**：
  这笔利润是基金历史上真金白银从市场赚取的。即便其中一部分利润已经被退出的成员拿回家消费或存银行，它依然属于“该基金自成立以来累计为所有出资人创造的总财富”。

---

### 3.2 累计总收益率（Total ROI）：存在严重统计失真

对**收益率百分比**而言，现有公式在有成员退出或大额出入金时，会产生**显著的扭曲与逻辑矛盾**。

#### 核心症结：分母是“历史累计总入金”——一个只增不减的沉没指标

1. **失真现象 1：沉没本金稀释后续回报（后人替前人背分母）**
   - 退出者的本金与利润虽然已经全部提走，但其历史上投入的本金作为常数**永远沉淀在了分母中**；
   - 一旦前期有大资金快进快出，哪怕后续留守资金赚取了数倍的回报，大盘总收益率也会因为分母巨大而被摊薄成微不足道的百分比。

2. **失真现象 2：为什么不能简单把分母改为“净入金 (入金 - 出金)”？**
   - 若分母改为 $\text{净入金} = \text{入金} - \text{出金}$；
   - 一旦投资业绩优秀，成员累计提取的现金超过了当初投入的初始本金，**净入金就会变成 0 甚至负数**；
   - 分母为负时，$\frac{\text{正收益}}{\text{负净入金}}$ 将得出荒谬的负收益率，数学模型直接崩溃。

3. **失真现象 3：丢失时间维度（忽略货币时间价值）**
   - 退出者的资金可能只放了 10 天，而留存者的资金放了 3 年；
   - 简单将历史所有入金直接相加作为分母，抹平了每笔资金的“在池时长（资本占用时间）”。

## 四、数例演算与推导

通过具体数值推演，可以直观看到现有简单收益率在退出场景下的失真程度：

### 阶段 1：两位成员建仓
- 成员 A 入金 **$1,000,000**（买入 1,000,000 份，NAV = 1.0000）。
- 成员 B 入金 **$10,000**（买入 10,000 份，NAV = 1.0000）。
- **基金状态**：总入金 = $1,010,000，总市值 = $1,010,000，NAV = 1.0000。

### 阶段 2：第一轮盈利 10%
- 投资获利 10%，总资产增值到 **$1,111,000**。
- NAV 升至 **1.1000**（A 价值 110 万，B 价值 1.1 万）。
- 累计总收益 = $101,000，**累计总收益率 = +10.00%**。

### 阶段 3：成员 A 全额退出
- 成员 A 按 NAV 1.1000 赎回全部 1,000,000 份，提走现金 **$1,100,000**。
- **基金状态**：
  - 剩余总资产 = $11,000（仅剩 B 的 10,000 份）。
  - 累计出金 = $1,100,000。
  - 累计入金 = $1,010,000。
  - NAV 依然保持 **1.1000**（份额赎回不改变单位净值）。
  - 累计总收益 = $11,000 + 1,100,000 - 1,010,000 = $101,000。
  - 累计总收益率 = $101,000 / 1,010,000 = **+10.00%**。

### 阶段 4：成员 B 留守，基金净值再次翻倍 (+100%)
- 基金经理运用 B 的 $11,000 资金再次取得优秀战绩，资产翻倍至 **$22,000**。
- NAV 跃升至 **2.2000**。
- **此时计算基金大盘指标**：
  - 当前总资产 = $22,000。
  - 累计出金 = $1,100,000（A 提走的）。
  - 累计入金 = $1,010,000（A 的 100 万 + B 的 1 万）。
  - **总收益额** = $22,000 + 1,100,000 - 1,010,000 = **+$112,000**（完全准确）。
  - **累计总收益率** = $\frac{112,000}{1,010,000} = \mathbf{+11.08\%}$！

#### 💥 矛盾结论：
- 成员 B 的本金实际赚了 **+120%**（从 1 万变成 2.2 万）；
- 基金经理连续两轮操盘（先 +10%，再 +100%），单位净值从 1.0000 飙升到 2.2000（**涨幅 +120%**）；
- **但大盘的“累计总收益率”卡片却只显示可怜的 +11.08%！**
- 原因就在于 A 已经带走的 100 万入金，依然死死锁在分母里，将真实投资业绩稀释了 10 倍以上。

## 五、金融行业通用解决方案与系统对比

在专业资产管理中，通常采用以下两套不同维度的指标来分别衡量“操盘水平”与“资本回报”：

| 指标类型 | 对应本系统指标 | 计算方式 | 是否受人员进出/退出影响 | 核心用途 |
| :--- | :--- | :--- | :--- | :--- |
| **时间加权收益率 (TWR)** | **单位净值 (NAV / Share)**<br>*(首页第 2 张指标卡)* | 份额净值化管理：进出金按当时净值折算/扣除份额，净值不因申赎发生跳变 | **完全不受影响** | 客观衡量**投资经理的实际投资能力与策略业绩** |
| **简单现金回报率 (Simple ROI)** | **累计总收益率 (Total ROI)**<br>*(首页第 3 张指标卡)* | `(总资产 + 累计出金 - 累计入金) / 累计入金` | **受退出与大额出入金严重扭曲** | 仅适用于成员固定、无大额频繁进出的极早期简单记账 |
| **资金加权收益率 (MWR / IRR)** | *（系统暂未内置）* | 考虑每笔资金实际存续日期的内部收益率（XIRR） | 结合了进出资金的时机与规模效应 | 衡量实际出资人在不同时点投入资金的综合真实年化回报率 |

### 💡 关键提示：系统其实已经内置了抗扭曲的客观指标！
系统的首页看板第二张卡片：**基金单位净值 (NAV / Share)**。
- 初始净值为 `1.0000`；
- 无论成员中途如何追加投资、提取现金、转让份额，还是全额清仓退出，**单位净值都能够不受资金进出的干扰，纯粹反映底层投资标的的涨跌**；
- 基金成立以来的真实策略累计回报率，本质上就等于：
$$\text{净值累计涨跌幅} = (\text{navPerShare} - 1) \times 100\%$$

## 六、后续优化建议与演进路径

为了避免看板上的“累计总收益率”在成员退出后误导家庭成员，建议采取以下渐进式改进方案：

### 方案 1：双指标呈现与口径说明（推荐，低成本高收益）
- **保留现有单位净值卡片**：明确其为“投资策略净值表现（TWR）”；
- **优化累计收益率卡片展示**：
  - 主数字可选：以净值累计涨幅 $(\text{NAV} - 1) \times 100\%$ 作为主指标（不受任何退出与出入金影响）；
  - 辅助文字显示：附带显示现金流总收益金额（如 `+$11.20 万 USD`）及基于资金进出的现金回报率；
- **指标说明 Tooltip**：在鼠标悬浮时提示两者的口径差异（“净值收益率反映操盘表现，现金收益率反映历史经手资金的账面回报”）。

### 方案 2：支持 XIRR（资金加权内部收益率）
- 针对每一笔存取款记录时间戳与金额；
- 计算 XIRR 年化收益率，真实反映不同成员资金在不同时间周期的复合年化回报率。

### 方案 3：个人端与大盘端分层
- **个人卡片**：如果某个成员已经全额退出（`shares = 0`），其个人卡片上的 `profitRate` 实际上是他这笔投资闭环的真实资本回报率（MOIC - 1），可标记为“已结清清算收益率”；
- **大盘卡片**：针对在管活跃资金，突出展示当前存量资金的加权表现与净值表现。

## 七、Codex 回复：采用“在管本金收益率”，不再重复展示 NAV 涨幅

Gemini 对现有公式局限性的判断基本成立，但需要补充一点：现有公式并非数学错误。它等价于：

$$
\frac{\text{当前资产}+\text{累计出金}}{\text{累计入金}}-1
$$

其含义更接近“历史总投入回报率（TVPI - 1）”。它适合回答“家庭历史投入的全部资金一共取得了多少回报”，但不适合作为当前仍在基金中的资金收益率。报告例子中的 `+11.08%` 与单位净值的 `+120%` 回答的是不同问题，不能简单认定前者计算错误。

本系统首页已经单独展示单位净值，因此不建议把第三张卡片再改成 `(NAV - 1)`，否则第二、第三张卡片本质上只是同一个指标的两种写法。结合本系统主要需要解决的场景——成员大额出金、部分退出或全额退出——第三张卡片建议改为：

### 在管本金收益率

$$
\text{在管本金收益率}
=
\frac{\text{当前基金资产}-\text{当前剩余本金}}{\text{当前剩余本金}}
\times 100\%
$$

该指标回答的是：**目前仍然留在基金里的本金，截至当前赚了多少。**

### 出金时的处理原则

不要求用户手工选择“利润出金”或“本金出金”。系统应按照实际处置的份额比例，自动同比拆分本金和利润。

假设某成员出金前：

- 剩余本金为 `$100`；
- 当前资产为 `$120`；
- 本次出金 `$60`，即处置当前仓位的 `50%`。

则系统自动认定：

- 本金出金：`$100 × 50% = $50`；
- 利润出金：`$60 - $50 = $10`；
- 出金后剩余本金：`$50`；
- 出金后剩余资产：`$60`；
- 在管本金收益率仍为 `(60 - 50) / 50 = 20%`。

因此，单纯的出金操作不会凭空制造收益率跳变；如果退出的是收益水平不同的成员，基金整体在管收益率会随剩余资金构成发生变化，这正是该指标希望反映的结果。

### 各类事件的统一规则

| 事件 | 当前剩余本金的处理 |
| :--- | :--- |
| 外部入金 | 增加该笔入金本金 |
| 部分出金 | 按实际处置份额比例减少对应成员的剩余本金 |
| 全额退出 | 该成员剩余本金归零，不再影响在管本金收益率 |
| 内部份额转让 | 只在成员之间转移对应本金，基金整体剩余本金不变 |
| 业绩报酬结晶 | 属于基金内部权益重新分配，不改变基金整体剩余本金 |

若存在退出业绩报酬，应先得到“现金支付份额、业绩报酬份额和总处置份额”，本金减少额以实际处置的 LP 仓位比例为准，业绩报酬单独列示，不能混入本金。

### 报表最终分工

首页三张核心卡片分别承担不同职责：

1. **累计收益金额**：继续使用 `当前资产 + 累计出金 - 累计入金`。正常出金时，当前资产减少额与累计出金增加额相互抵消，因此累计收益金额不会因大额出金本身发生变化。
2. **单位净值**：继续反映基金策略和底层资产的整体走势，不受正常申购赎回影响。
3. **在管本金收益率**：反映目前尚未退出的本金表现；退出成员的历史本金不会永久留在分母中。

原“累计总收益率”可以从首页主卡片移除，必要时在详情页更名为“历史总投入回报率”，作为辅助统计保留。

### 实现注意事项

“剩余本金”应作为独立的 ROI 成本字段维护，不应直接复用当前 LP 批次中的 `basis`。现有 `basis` 还承担业绩报酬门槛和高水位计算职责，结晶时可能重置为新的计费基准；若与原始未返还本金混用，会导致结晶操作无意中改变在管本金收益率。

建议为 ROI 单独维护类似 `remainingPrincipal` 的状态：入金时增加，出金时按处置比例减少，内部转让时在成员间同比转移。该字段只服务于在管本金统计，不参与业绩报酬计算。

当当前剩余本金为零时，在管本金收益率没有有效分母，应显示 `—`，而不是显示 `0%` 或无限收益率。
