## 复审中发现并修正的回归

- 删除请求成功后过早移除 pending 标记，仍可能让删除刷新打断新试算：pending 持续到刷新完成。
- 仅在通用 API 层等待删除，会晚于试算捕获的版本号：试算入口先等待，再捕获版本。
- 所有 DELETE 豁免等待会让成员删除越过待删除交易：仅交易删除本身豁免。
- 把历史汇率回显四舍五入会改变历史现金流：保留原精度，调整输入 step。
- 切换账本会取消旧页面计时器：导航先等待删除，并在失败时保持当前账本。

## 未作为缺陷改动的事项

- 损坏账本阻止全局生成新成员编号是防止编号碰撞的保守保护；不静默跳过无法读取的成员集合。
- 未知所有者的空锁目录、恢复目录采用拒绝自动接管策略，避免误删活跃锁。
- 空账本总览收益率 null 是已测试的无分母语义，不擅自改为 0。
- 历史 V3 同高水位合批的极小 Decimal 舍入差异不改变显示金额；直接改批次会破坏已锁定快照，未改变历史算法。
- 受校验白名单约束的成员/事件 ID 和合法日期，没有原报告假设的任意 HTML 注入路径。
