# #5、#7、#8、#15 修复与连续独立审查（2026-10-04）

范围为 [2026-10-03 审查](./CODE_REVIEW_2026-10-03.md) 的四项遗留问题及受影响路径。测试使用隔离数据目录，不扫描或修改用户账本。本轮不改变财务计算公式、历史算法版本和事件排序规则。

## #5：计算层业务错误分类

费率越界或类型非法，以及入金、出金、转让前无法定价的零净值，改用 `InputError`，以 HTTP 400 / `INPUT_ERROR` 返回可操作的中文原因。内部批次汇总不变量错误与存储异常继续按内部故障处理，不把任意异常转换成客户端错误。

回归覆盖非法门槛和报酬费率、合法边界、零净值历史账本、写请求和状态读取；失败写请求不落盘，账本保持不变。既有存储 500 隐藏规则继续保留。

## #7：日期校验先于锁账比较

新增出入金、内部转让先检查日期非空、类型、格式与真实日历日期，再判断结算锁账。移除原位置的重复日期检查，周日规则保留。

回归在已锁账数据上提交数字、布尔值、对象、数组、非法日历日期及空日期，均返回输入错误；合法锁定日期仍返回 HTTP 409 / `BUSINESS_CONFLICT`。拒绝请求不计算、不写入。

## #8：代理凭据不进入子进程参数

显式代理地址改经 curl 子进程的代理环境变量传递，命令行不含代理 URL。使用独立环境对象，清除相互竞争的旧代理配置和应用专用变量，保留 `NO_PROXY` 规则与直连策略，不修改父进程环境。环境代理模式继续使用 curl 原有优先级。

测试检查 Windows 注册表代理、自定义代理、Socks 地址、冲突环境、绕过规则、失败信息脱敏及父环境不变；真实 curl 连接本机临时 HTTP 代理，验证测试凭据的认证和 JSON 结果。额外一次性探针验证 HTTPS CONNECT 的代理选择及测试凭据认证，以及 `NO_PROXY` 的真实直连绕过。响应字节限制、UTF-8 与真实 HTTP 流回归仍通过。

## #15：数据目录单实例保护

新增 `lib/data-directory-lock.js`，使用账本目录内的原子目录创建取得独占权。存储模块在任何读取、迁移或事务恢复前取得锁，后续账本和缓存访问复核所有权；使用不同监听端口也无法绕过。同一进程内的第二个存储模块也会被拒绝，显式交接锁后才能重新加载；释放后的旧存储引用不能继续读写。

正常进程退出及初始化失败释放自有锁；CLI 的 SIGINT / SIGTERM 先停止接受 HTTP 请求，待请求结束后退出并释放锁。断电、强制终止或归属不明的锁一律拒绝自动抢占，避免 NAS 上不同主机的 PID 空间被误认为同一实例。README 记录了单实例约束、升级前停止旧进程及确认全部实例停止后的手工恢复步骤。

隔离子进程测试覆盖争抢拒绝、退出后重新启动、死 PID / 异地主机 / 缺失所有者信息时失败关闭、拒绝时账本及事务日志不变、取得锁后才恢复、所有权丢失、元数据写失败及初始化失败释放。真实 CLI 测试验证第二个不同端口服务拒绝共用账本，SIGTERM 处理后退出并释放锁；额外注入监听 `EACCES` 错误，确认退出码为 1 且自有锁释放。
