# #9、#12 修复与独立复核（2026-10-04）

本记录针对 [2026-10-03 审查](./CODE_REVIEW_2026-10-03.md) 的 #9、#12。其他问题状态见[审查总表](../CODE_REVIEW.md)。本轮不改动用户账本，不构成全项目无缺陷保证。

## #9：外部 JSON 响应大小限制

- 直连使用 Buffer 分块累计实际字节数，预算为 10 MiB（10 × 1024 × 1024 字节）；恰好达到上限可解析，超过一字节即拒绝并销毁响应和请求。超限后释放已收集分块。
- Content-Length 超限时提前拒绝；缺失或伪造较小的声明不绕过实际流量检查。
- 大小错误使用 `EXTERNAL_RESPONSE_TOO_LARGE` 标识，不再通过 curl 备用请求下载同一超限响应；普通网络失败仍沿用原备用传输策略。
- 代理路径为 HTTP 状态尾部留出缓冲余量，并在解析前复核 JSON 正文字节数。子进程缓冲区超限归入同一大小错误。
- Buffer 合并后一次性解码 UTF-8，避免中文或 emoji 跨数据块时被破坏。

测试覆盖恰好 10 MiB、+1 字节、累计多块、缺失/伪造/超大声明长度、跨块 UTF-8、中文多字节超限、代理正文边界、子进程 maxBuffer，以及本机临时 HTTP 服务的真实流式断开。真实服务在隔离测试中运行，不调用行情服务或正式账本。

## #12：查价索引

- 新增 `lib/date-lookup.js`：一次筛选和排序后，使用二分查找得到严格早于日期或包含当日的最近记录。
- 每次行情物化为每个需要的标的创建一个索引，两套自定义基准复用相同标的索引；不再为每个日期重复排序。
- 每轮计算为旧指数缓存及两个自定义基准缓存建立独立的有效记录索引。保留精确日期缓存优先、无效签名/价格过滤及未来价格排除规则。
- 索引限制在当次计算/生成周期内使用；不以对象身份全局缓存，防止原地更新后读取陈旧价格。导出的旧查询函数保留独立调用兼容性，批量调用通过工厂复用索引。
- 演示行情生成脚本改为每个标的一次建立索引。

新增 231 个账本日期、6 个标的、约 14 年行情的测试，覆盖周末、缺失报价和两套自定义基准；用原筛选排序算法作为参考，逐项比较缓存以及完整账务和图表输出。测试还检查索引复用时不重复读取源价格，以及源价格修改后重新建立索引会得到新结果。

本机单次测量：参考物化约 170–175ms，新物化约 8ms，含完整行情的回放约 16–17ms。该测量仅用于相同工作负载比较，不是所有设备的延迟保证；既有回放性能测试仍保留。
