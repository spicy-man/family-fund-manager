## 独立审查发现的补修

初次第一轮独立审查通过，初次第二轮发现临时预览固定 ID 与合法导入 ID 冲突：导入入金 ID 为 preview_settlement 时，预览取得入金结果，前端报错；直接 API 确认仍可能与该错误预览不一致。已补修为确定性生成未被活动事件占用的临时 ID，并同时按 ID、事件类型和日期查找计算结果。补充单个及连续候选冲突、完整快照相等和真实跨版本备份导入回归。

补修后完整 34 个脚本重新通过，连续独立验收从零重新计数。下面记录补修后两轮结论。
