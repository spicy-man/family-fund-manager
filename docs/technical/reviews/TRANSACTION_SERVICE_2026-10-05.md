## 完成范围

`routes/transactions.js` 从 488 行缩至 61 行，只负责读取请求参数、调用服务及返回原有成功/错误信封。`lib/transaction-service.js` 暴露入出金创建、估值创建、内部转让、事件删除和事件修改五项同步操作，不依赖 HTTP 请求或响应对象，也不加载存储模块。

服务集中构造候选账本、检查重放结果及提交保存。候选账本独立复制，避免输入、重放或保存失败时污染共享读取对象；保存成功后才提交新事件顺序号并触发行情同步。删除仍不触发行情同步，修改和删除不重新分配顺序号，持久化高水位保持原行为。

各事件的输入校验、原/目标日期锁账、LP/GP 身份约束、历史余额、费率快照、全额退出、旧版全额转让、历史汇率与手动人民币金额规则原样迁移。新建和修改使用同一次校验重放完成金额核对与整本账本检查；删除也只重放一次。未修改计算器、存储格式或财务算法。

本机版和演示沙盒继续通过同一 `registerApiRoutes` 装配服务，不引入新依赖；后续 TASK-016～018 保留待办。
