## 已完成

### [x] TASK-001：将 `indexCache` 从 `db.json` 分离

完成日期：2026-08-11

- 新增独立的 `data/index-cache.json`，只保存可重新获取的标普 500/纳指 100 历史收盘缓存。
- 旧版 `db.json` 中的 `indexCache` 会在首次读取时原子迁移，缓存文件写入成功后才移除旧字段。
- 指数后台刷新不再调用账本 `writeDb()`，因此不会重写 `db.json` 或生成核心账本 ZIP 备份。
- 新导出和自动 ZIP 快照不再包含指数缓存；旧 ZIP 中内嵌的 `indexCache` 仍可兼容恢复。
- 已迁移当前真实数据：111 条缓存记录，迁移前后自动 ZIP 数量均为 7。
- 已通过完整 `npm test`，共 19 个测试文件。
- 自审已覆盖迁移中断后重试、旧字段与既有缓存冲突合并、损坏缓存降级及日志防洪。

### [x] TASK-002：减少单次请求中的重复全量重放（P0）

完成日期：2026-08-11

- 出金、转让及事件修改统一通过一次校验重放获得交易前余额、账本合法性、全额退出判断和最终事件金额，不再分别调用 3-4 次 `calculateStateFromDb()`。
- 全额退出识别移入候选事件的同一次重放；只对当前请求指定的事件启用，不改变历史未标记事件的回放语义。
- 校验重放可省略体积较大的 `_disposedLots` 展示明细，但仍逐条处理全部历史事件、全部批次和所有 Decimal 财务计算。
- API 回归测试直接统计计算器调用次数，覆盖全额出金创建、出金修改和转让创建，均严格为一次。
- 自审修复了两位小数展示余额与精确 Decimal 余额之间的全退识别兼容问题；100 组小数余额差分验证与旧请求流程完全一致。

### [x] TASK-003：减少重放中的重复批次遍历和聚合开销（P1）

完成日期：2026-08-11

- `previewDisposalFee` 将批次份额、门槛、价值、报酬和扣费后净值合并为一次昂贵聚合，第二次遍历同时生成审计明细并应用批次扣减，移除了原先的多次 `map/reduce` 和额外扣减遍历。
- 回放成员状态增加只存在于内存的 `lpShares` 批次汇总，并在入金、处置、转入和 v1/v2/v3 结算时同步更新，消除每次处置前及最终输出时对全部批次的重复求和。
- 未采用持久化派生索引或局部跳跃重放：历史事件可携带不同费率版本，且逐批处置明细是审计输出；复杂失效规则带来的正确性风险高于当前收益。当前选择是可由完整批次数组逐次验证的内存汇总。
- 新增“150 个入金批次 + 80 次出金”基准：共 24,000 次批次访问（每次处置严格为聚合、应用各一次），精简校验模式与完整明细模式的份额、净值、业绩报酬和人民币台账完全一致。
- 当前实现仍保留“处置数 × 活动批次数”的增长特征；本任务降低了常数、重复遍历和请求内重放次数，不宣称已经消除最坏情况下的二次增长风险。
- 自审恢复了逐批 Decimal 运算顺序并保留旧版处置产生的零份额审计批次；重构前后 200 组随机账本逐字段一致，另有 300 组随机账本通过精简/完整模式等价和批次汇总不变量检查。
- 已通过完整 `npm test`，共 20 个测试文件。

### [x] TASK-004：本地化前端第三方依赖并增加页面安全策略（P1）

完成日期：2026-08-11

- Chart.js、SortableJS、Inter 和 Outfit 分别固定为 `4.5.1`、`1.15.7`、`5.3.0` 和 `5.3.0`，版本与包完整性写入 `package-lock.json`。
- 浏览器改用带版本号的本地 `/vendor/` 资源；脚本、字体样式和字体文件均由本机 Express 服务提供并使用一年 immutable 缓存，断网不再影响图表、拖拽排序或字体加载。
- 移除 jsDelivr 和 Google Fonts 外链；页面及其运行时依赖不再向第三方站点发起资源请求，也不再把账本页面执行权限交给 CDN 脚本。
- 所有响应增加 Content Security Policy：脚本只允许同源且禁止内联脚本和内联事件处理器，连接、字体和图片按当前功能最小授权，禁止 frame、media、worker、manifest、对象、基址注入和跨页面嵌入。
- 现有页面和运行时模板仍大量使用 `style` 属性，因此 CSP 仅对样式属性保留 `'unsafe-inline'`；`style-src-elem 'self'` 继续禁止内联样式块和外部样式源。
- 新增本地依赖与 CSP 集成测试，覆盖精确版本、锁文件、无 HTTP 外链、无内联脚本、策略指令、API 响应、页面完整资源图、资源类型、路径逃逸和不可变缓存。
- 已通过完整 `npm test`，共 21 个测试文件。
